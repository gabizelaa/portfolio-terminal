# Gabizela's Terminal v2.0 🚀

Um portfolio interativo em formato de terminal com design moderno, temas claro/escuro e funcionalidades avançadas. Refatorado seguindo as melhores práticas de desenvolvimento web.

## ✨ Funcionalidades

### 🎨 Interface Moderna
- **Temas Light/Dark**: Alternância suave entre temas claro e escuro
- **Design Responsivo**: Otimizado para desktop, tablet e mobile
- **Animações Suaves**: Transições e efeitos visuais elegantes
- **Acessibilidade**: Suporte completo a leitores de tela e navegação por teclado

### ⚡ Funcionalidades Avançadas
- **Histórico de Comandos**: Navegação com setas ↑/↓
- **Atalhos de Teclado**: Ctrl+L (limpar), Ctrl+K (tema)
- **Persistência de Tema**: Lembra a preferência do usuário
- **Scrollbar Customizada**: Barra de rolagem estilizada
- **Loading Lazy**: Carregamento otimizado de imagens
- **Spotify Player Integrado**: Player interativo com a playlist "oi" (900+ músicas)

### 🎯 Comandos Disponíveis

| Comando | Descrição | Idioma |
|---------|-----------|--------|
| `ping` | ヘ(^_^ヘ) | EN |
| `about` / `sobre` | Informações pessoais | EN/PT |
| `pets` | Galeria dos pets | EN |
| `projects` / `projetos` | Portfolio de projetos | EN/PT |
| `skills` | Habilidades técnicas | EN |
| `studies` / `estudos` | Formação acadêmica | EN/PT |
| `social` | Redes sociais | EN |
| `career` / `carreira` | Experiência profissional | EN/PT |
| `playlist` | Gosto musical | EN |
| `meme` | Memes aleatórios em ASCII 🎲 | EN |
| `theme` | Alternar tema | EN |
| `help` | Lista de comandos | EN |
| `clear` | Limpar terminal | EN |

### ⌨️ Atalhos de Teclado

- **Ctrl + L**: Limpar terminal
- **Ctrl + K**: Alternar tema
- **↑/↓**: Navegar histórico de comandos
- **Enter**: Executar comando

## 🛠️ Tecnologias

### Frontend
- **HTML5**: Estrutura semântica e acessível
- **CSS3**: Custom properties, Grid, Flexbox, Animações
- **JavaScript ES6+**: Classes, Async/Await, Modules
- **Bootstrap 5.3**: Framework CSS responsivo

### Arquitetura
- **Modular**: Código organizado em classes ES6

## 🔧 Instalação

1. Clone o repositório:
```bash
git clone https://github.com/gabizelaa/portfolio-terminal.git
```

2. Navegue até o diretório:
```bash
cd portfolio-terminal
```

3. Abra o arquivo `index.html` no navegador
